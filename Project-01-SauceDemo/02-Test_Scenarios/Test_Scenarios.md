# Test Scenarios

This spreadsheet contains the test scenarios I created for my SauceDemo manual testing project.

**[View Test Scenarios](https://docs.google.com/spreadsheets/d/1yf3X0Tc59sNWkeS_ekP5Q8Ukz2bqpo01aJppxhoIDis/edit?gid=473129140#gid=473129140)**

## Modules Covered

- **Login:** Valid and invalid login attempts, locked-out accounts, password visibility, and logout.
- **Products:** Product display, sorting, and product interactions.
- **Shopping Cart:** Adding and removing products, and reviewing cart contents.
- **Checkout:** Entering checkout information, reviewing order details, and completing the checkout process.

## Test Types

Functional Testing, Usability Testing, Compatibility Testing, Accessibility Testing, Security Testing, and Performance Testing.

## Test Approaches

Positive Testing, Negative Testing, and Exploratory Testing.

*This spreadsheet is part of my personal manual testing portfolio. SauceDemo is used as a demo application for learning and practicing manual testing.*
