# Login Test Scenarios

This page contains the test scenarios I created for the **Login** module of the SauceDemo manual testing project.

## Test Scenario Document

The test scenario list is maintained in Google Sheets so it can be updated as the project progresses.

**[View Login Test Scenarios on Google Sheets](https://docs.google.com/spreadsheets/d/16645TahYr9-Rr0N0DaJYQn2HUXgKVnToGvBB_Jfga3k/edit?gid=1969699739#gid=1969699739)**

## Scope

The Login test scenarios cover:

- Login with valid credentials
- Login attempts using a locked-out account
- Login attempts with invalid credentials
- Login attempts with empty required fields
- Password masking
- Information displayed in login error messages
- Logout functionality
- Access to the Products page after logout
- Login page controls and usability
- Keyboard accessibility
