# SauceDemo Manual Testing Project

## Overview

This project demonstrates my Manual QA Testing skills through testing SauceDemo, a publicly available e-commerce demo application.

The project covers the software testing process, including test planning, test scenario creation, test case design, test execution, defect reporting, and test summary documentation.

## Application Under Test (AUT)

| Attribute | Details |
|---|---|
| Application | SauceDemo |
| URL | [https://www.saucedemo.com/](https://www.saucedemo.com/) |

| Testing Type | Manual Functional Testing |

## Testing Objectives

- Validate the core functionality of the application.
- Verify key business workflows, from login to checkout.
- Identify and document functional defects and usability issues.
- Demonstrate structured QA documentation and testing practices.
