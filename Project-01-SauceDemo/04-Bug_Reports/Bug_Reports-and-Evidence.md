# Bug Reports

This documentation contains the bug reports recorded during my SauceDemo manual testing project.

**[View Bug Reports](https://docs.google.com/spreadsheets/d/1yf3X0Tc59sNWkeS_ekP5Q8Ukz2bqpo01aJppxhoIDis/edit?gid=272334897#gid=272334897)**

Bug reports are created when the actual application behavior does not meet the expected result during test execution.

## Bug Report Details

Each bug report includes:

- Bug ID
- Related Test Case ID
- Bug Title
- Module
- Environment
- Preconditions
- Steps to Reproduce
- Expected Result
- Actual Result
- Severity
- Priority
- Status
- Reported Date
- Evidence

## Evidence

Screenshots are included to support reported findings and show the actual application behavior.
