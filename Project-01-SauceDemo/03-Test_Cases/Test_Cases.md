# Test Cases

This spreadsheet contains the test cases I created based on the test scenarios for my SauceDemo manual testing project.

**[View Test Cases](https://docs.google.com/spreadsheets/d/1yf3X0Tc59sNWkeS_ekP5Q8Ukz2bqpo01aJppxhoIDis/edit?gid=1969699739#gid=1969699739)**

## Modules Covered

- **Login:** Testing login functionality, credential validation, locked-out accounts, password visibility, and logout.
- **Products:** Testing product display, sorting, and product interactions.
- **Shopping Cart:** Testing adding and removing products, and verifying cart contents.
- **Checkout:** Testing checkout information, order details, and order completion.

## Test Case Details

Each test case includes:

- Test Case ID
- Related Test Scenario ID
- Test Case Description
- Preconditions
- Test Steps
- Test Data
- Expected Result
- Actual Result
- Status
- Priority

## Test Execution

Test cases are executed manually using SauceDemo. The actual results and execution status are recorded based on the observed application behavior.

*This spreadsheet is part of my personal manual testing portfolio. SauceDemo is used as a demo application for learning and practicing manual testing.*
